# Meta 3.2: Índices, loc e iloc en pandas

## Descripción

En esta actividad utilicé Python y pandas para practicar cómo seleccionar y modificar datos de un DataFrame.

El programa crea una tabla con las ventas de los productos A, B y C durante enero, febrero y marzo. Las ventas iniciales son números aleatorios entre 100 y 1000.

## ¿Qué hace el programa?

- Selecciona ventas por el nombre del mes y del producto con `loc`.
- Selecciona ventas por la posición de filas y columnas con `iloc`.
- Cambia las ventas del producto B en marzo a 1200.

## Archivo

`Meta 3.2 Implementar Indices y funciones loc e iloc en pandas.py` contiene el programa y las pruebas de cada ejercicio.

## Requisitos

Python 3, pandas y NumPy.

## Ejecución

Desde la carpeta del proyecto, ejecutar:

`python3 "Meta 3.2 Implementar Indices y funciones loc e iloc en pandas.py"`
